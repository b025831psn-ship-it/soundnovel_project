# 제절초 PS1 웹 포트

이 경로는 이슈 #37의 공개 작업 영역이다. 목표는 PS1판 《제절초》(弟切草)를
원작 실행과 대조 가능한 방식으로 웹에 옮기고, 같은 고정 ID를 사용하는 한글화
파이프라인을 만드는 것이다.

## 경계

- 원본 디스크, BIOS, 메모리 카드, 세이브, 원본 실행 파일, 추출 미디어와
  네이티브 추적 원본은 Git에 넣지 않는다.
- 공개 저장소에는 분석·변환 도구, 형식 문서, 직접 만든 fixture와 테스트,
  원본 데이터를 포함하지 않는 웹 런타임만 둔다.
- 배포 웹은 BIN/CUE, ISO, BIOS나 PS-X EXE를 읽거나 사용자에게 요구하지 않는다.
- 원본에서 생성한 작품별 메타데이터·대사·미디어는 별도 비공개
  `otogirisou-ps1-kor` 저장소에 둔다. 저장소가 준비되기 전에는 로컬 Git 제외
  경로에서만 다룬다.

## 첫 수직 슬라이스

부팅과 타이틀에서 새 게임으로 들어가 첫 사용자 입력과 첫 선택지를 통과하는
구간을 먼저 완성한다. 화면을 비슷하게 다시 그리는 것으로 완료하지 않고,
원본의 제어 흐름과 다음 이벤트를 순서대로 대조한다.

- CPU PC/opcode 및 상태를 바꾸는 쓰기
- CD LBA 읽기
- GP0/GP1 명령과 VRAM/CLUT 전송
- SPU 레지스터·DMA, XA/STR 섹터
- VBlank와 컨트롤러 표본

## 시작 방법

소유한 디스크의 실제 경로는 저장소 밖에 둔다. 먼저 로컬 인벤토리를 만든 뒤
민감한 파일명이나 원본 데이터가 섞이지 않았는지 검토한다.

```sh
python3 tools/validate_disc_manifest.py /private/path/disc-manifest.json
python3 -m unittest discover -s tests -v
```

아직 기준 디스크가 작업공간에 없으므로 판본 해시, 디스크 ID, 실행 파일과
컨테이너 구조는 확정하지 않았다. 추측값을 코드에 넣지 않는다.
