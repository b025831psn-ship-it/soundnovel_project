# 428 PSP 번역 데이터 형식

실제 대사는 비공개 하위 리포 `428-psp-kor`에만 둔다. 이 문서와 아래 예문(직접 쓴 가짜 문장)만 공개 저장소에 둔다.

## 원문 (`428-psp-kor/data/script-ja/<스크립트>.json`)

`tools/export-script.mjs <to.sns> <출력폴더>`가 만든다. 스크립트 하나(예: `k01` = 加納 1장)에 파일 하나, 항목은 게임 진행 순서다.

```json
{
  "script": "x01",
  "entries": [
    { "id": "X01A_0010_0100/1", "pc": 10240, "ja": "{鈴木|すずき}は時計を見た。", "end": "1B" },
    { "id": "X01A_0010_0100/2", "pc": 10288, "ja": "まだ来ない……", "end": "1F" },
    { "id": "X01A_0010_0110/1", "pc": 10400, "ja": "どうする？", "end": "18", "center": true },
    { "id": "X01A_0010_0110/c1", "pc": 10452, "choice": [{ "label": "X01A_0010_0120", "slot": 0 }, { "label": "X01A_0010_0130", "slot": 0 }], "timer": 0 }
  ]
}
```

- `id`: 고정 ID = `장면 라벨/순번`. 장면 라벨은 원작 스크립트의 라벨(0x56)이고 순번은 그 장면 안의 줄 번호다. 전체에서 겹치지 않는다. 번역문·검수 의견은 이 ID에 연결한다.
- `pc`: 스크립트 안 바이트 위치(재삽입·대조용). 번역에서는 쓰지 않는다.
- `ja`: 원문 한 줄.
  - 루비 `{본문|읽기}`
  - `…` = 말줄임 칸(원작 명령 43)
  - `―` = 대시 칸(명령 2B, 개수 = 칸 수)
  - `\n` = 원작이 강제로 바꾼 줄(명령 1E). 자동 줄바꿈은 들어 있지 않다.
- `end`: 이 줄을 끝내는 명령.
  - `1B` 줄 대기(▶)
  - `1F` 페이지 대기(책 아이콘, 다음에 화면 지움)
  - `25` 글자 블록 끝
  - `18` 가운데 정렬 구간 끝
  - `2B` 대시 뒤 대기
  - `label`/`choice`/`eof` 구간 경계
- `center`: 검은 화면 가운데 정렬 문장(명령 17–18).
- `choice`: 선택지 명령. 선택지 글은 바로 앞 줄들에 나온다. `label`은 이동할 장면이라 번역하지 않는다.
- `index.json`: 스크립트별 줄·선택지 수.

## 번역문 (`428-psp-kor/data/script-ko/<스크립트>.json`)

```json
{
  "script": "x01",
  "model": "gpt-6-luna",
  "entries": [
    { "id": "X01A_0010_0100/1", "ko": "{스즈키|すずき}는 시계를 보았다." },
    { "id": "X01A_0010_0100/2", "ko": "아직 안 온다……" },
    { "id": "X01A_0010_0110/1", "ko": "어떻게 하지?" }
  ]
}
```

- 원문의 모든 `ja` 항목에 같은 `id`로 `ko`를 하나씩 둔다. 선택지 항목(`choice`)은 넣지 않는다.
- 루비는 필요할 때만 `{본문|읽기}`로 둔다. 인명 루비는 빼도 된다.
- `…`과 `―`는 그대로 쓴다. 재삽입할 때 원작 명령으로 바꾼다.
- `\n`은 원문에 있던 자리만 유지한다. 줄 길이는 엔진이 맞춘다.
- `end`, `pc`, `center`는 원문 파일에서 읽으므로 번역문에 다시 적지 않는다.
- `model`: 실제 응답 모델 ID. 항목별로 다르면 항목에 `"model"`을 적는다. 토큰 사용량은 `data/script-ko/usage.json`에 스크립트별로 기록한다.
- 자동 검사 항목: ID 누락·중복, 빈 `ko`, 루비 괄호 짝, `\n` 개수가 원문과 같은지, 미지원 문자.
