# 공개 데이터 경계

이 폴더에는 SLPS-01863을 분석·재현하는 코드, 주소·건수·해시만 둔다. 다음 자료는 현재 트리뿐 아니라 공개 Git 이력에도 넣지 않는다.

- 디스크와 디스크에서 꺼낸 파일: BIN, CUE, ISO, STR, `SLPS_018.63`, `SCRP.D`, `SYSTEM.CNF`
- 추출·변환 자산: 시나리오 대사, 그림, 영상, 음악, 효과음, KF1, 생성 한글 글꼴, 메모리 카드와 상태
- 비공개 포트 데이터와 번역 결과

비공개 `majo-tachi-ps1-kor`에는 대사와 웹 포트 데이터만 둘 수 있다. 디스크 파일은 비공개 저장소에도 넣지 않는다. 공개 빌드는 `translation.lock.json`의 커밋을 읽되 본문을 복사하지 않는다.

`tools/check_public_tree.py`는 HEAD까지의 모든 경로와 blob을 훑는다. 현재 파일을 지운 것만으로는 통과하지 않으므로 실수로 커밋했다면 공개 푸시 전에 이력을 정리해야 한다.
