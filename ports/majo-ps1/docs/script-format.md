# 『마녀들의 잠 부활제』 PS1 대본 형식

대상은 일본 일반판 `SLPS-01863`이다. 사용자 소유 디스크에서 꺼낸 `SLPS_018.63`과 `SCRP.D`를 읽기 전용 입력으로 사용한다. 공개 저장소에는 대사, 디스크 파일, 실행 파일 바이트를 넣지 않는다.

```sh
python -B ports/majo-ps1/tools/extract_script.py \
  --exe /path/to/SLPS_018.63 \
  --scrp /path/to/SCRP.D \
  --output /new/private/output
```

출력은 `script.ja.json`, `md/`, `uncovered.json`, `extra/`, `manifest.json`이다. 실제 출력은 작품의 비공개 저장소에만 둔다.

## 디스크와 압축

실행 파일의 `0x4C5AC`에는 24바이트 항목 598개로 된 `SCRP.D` 색인이 있다. 항목은 12바이트 이름, 플래그, 그룹, 2,048바이트 섹터 번호, 압축 크기 순서다. 시나리오는 `A10.BIN`, `A11.BIN`, `A20.BIN`, `A21.BIN`, `A30.BIN`, `A40.BIN`, `A50.BIN`, `A60.BIN`, `A70.BIN`에 있다.

압축 해제기는 EXE 루틴과 같은 4 KiB LZSS 링을 쓴다. 링은 공백으로 채우고 쓰기 위치는 0에서 시작한다. 플래그는 낮은 비트부터 읽는다. 1이면 리터럴이고, 0이면 두 바이트 역참조다. 역참조 위치는 `a | ((b & 0xF0) << 4)`, 길이는 `(b & 0x0F) + 3`이다.

## 레코드와 명령

레코드는 `FE`와 11바이트 ASCII 레이블로 시작한다. 일부 레이블의 빈자리는 `CR 00`, 나머지는 공백 또는 0으로 채운다. 시나리오 명령은 `40 opcode`이며 EXE의 `0x8001C36C` 디스패처가 `0x00`부터 `0x14`까지 처리한다. 점프 테이블은 EXE 주소 `0x800102E0`에 있다. 본문은 명령 `40 01`이다. 본문의 CP932 문자에서 `40`은 두 번째 바이트가 될 수 있으므로, 다음 명령을 찾을 때 CP932 선행 바이트를 함께 건너뛴다. 반대로 주소 피연산자의 마지막 바이트가 우연히 CP932 선행 바이트일 수 있으므로 본문 시작 `40 01`은 레코드 바이트열에서 직접 찾는다. 모든 후보를 CP932로 엄격하게 해독하며 실패하거나 빈 본문이면 추출을 중단한다.

ID는 카마이타치 PS1판과 같은 `RRR-SSS-OOOO`다.

- `RRR`: 9개 시나리오 리소스 순번
- `SSS`: 리소스 안 레코드 순번
- `OOOO`: 12바이트 레코드 머리 뒤에서 잰 본문 명령 오프셋

인라인 `@r`, `@k`, `@p`, `@q`, `@g`, `@n`, `@0`, `@1`, `@wNN`, `@lNN,NN`은 각각 대괄호 코드로 보존한다. `[g]` 또는 `[q]`가 들어간 항목은 PS1판 자체 선택지 묶음이므로 `beforeChoice: true`를 붙인다. 이 판본은 선택지 문구를 별도 레코드가 아니라 한 본문 명령 안에서 `[g]`와 `[q]`로 구분한다.

`uncovered.json`은 본문 명령 전체가 엄격한 CP932로 해독되고 미해독 문자열이 없을 때만 빈 배열이다. `extra/ps1-exe-strings.json`은 메뉴, 메모리 카드, 엔딩 제목 등 EXE 고정 문자열을, `extra/name-judgment.json`은 이름 판정용 일본어 문자열을 담는다.

## 명령 해석기 범위

`src/scenario-vm.mjs`는 원본 디스패처의 `00`~`14`를 모두 처리한다. 실제로 없는 명령을 다음 명령까지 건너뛰면 손상된 포트 데이터가 정상처럼 보이므로, 범위 밖 opcode는 주소와 함께 즉시 실패한다.

| opcode | 동작 | opcode | 동작 |
| --- | --- | --- | --- |
| `00` | 레코드 표제 | `0B` | 효과음 뱅크 초기화 |
| `01` | 본문·선택지 | `0C` | 화면 전환 |
| `02` | 무조건 점프 | `0D` | 플래그 산술 |
| `03` | 값 일치 분기 | `0E` | 플래그 비트 설정 |
| `04` | 미만 분기 | `0F` | 플래그 대입 |
| `05` | 선택지 준비 | `10` | 엔딩 기록 |
| `06` | 선택 결과 분기 | `11` | 진동 |
| `07` | 그림 표시 | `12` | 컨트롤러 판정 |
| `08` | STR 재생 | `13` | 화면 효과 |
| `09` | 음악 | `14` | 그림 선행 적재 |
| `0A` | 효과음 |  |  |

`compare_scenario.py`와 `compare_handlers.py`는 사용자 소유 `SLPS_018.63`의 원본 MIPS 루틴을 Unicorn으로 실행해 JS 해석기와 PC·플래그·난수·선택지 상태·장치 호출 인자를 비교한다. `test_scenario_vm.mjs`는 21개 case가 빠짐없이 존재하며 범위 밖 명령이 조용히 통과하지 않는지 독립적으로 검사한다.
